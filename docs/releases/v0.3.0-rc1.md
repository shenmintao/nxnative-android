# nxnative-android 0.3.0-rc1

This candidate renames the fork and desktop executable to **nxnative-android**, retaining the upstream runtime, profile provenance and MIT license. Windows is the intended desktop bundle target; binary bundle verification is pending. Game files, keys, game APKs and data packs are not distributed.

**Held for investigation:** subsequent manual tablet play reproduced stutter outside the acceptance route: 58.004 fps in a 120 s diagnostic capture, 33 intervals >50 ms, 12 >100 ms, max 241.680 ms. Pipeline creation counters rose by 388 around that window. The desktop source passed 153 tests including three new entrypoint checks; the Windows bundle build was stopped before verification and no candidate assets have been published.

## Changes

- Direct NSP/XCI import with matching updates/DLC, embedded APK data by default and external data for large games.
- PPE2 graphics and compute prewarming, backward-compatible with existing prewarm input.
- Upstream generic lock-poll spin-wait detection (`seedds/nxnative` `2c31212`); the extra sync-caller affinity experiment stays off.
- Reviewed nx2android updates through `8e030b41`, including ADPF workload hints and rendering fixes. The local memory-pool range index/cache is retained; skip-draw background compilation stays off by default.
- Upstream motion fusion from `99330eb8`, Android calibrated gyro/accelerometer integration, background reset, and optional hitch diagnostics.
- Public executable commands (`profiles`, `doctor`, `convert`) and compatible `-m porter` / Python-script dispatch; settings and signing keys default to `tools/player` beside the executable.

## Verification

BotW 1.9.0 on TB323FU / SM8850P / Adreno 840 / Android 16, balanced mode, owned Great Plateau save. Docked output 1920×1080; stock internal DRS retained, 1600×900 in sampled scenes. Each window uses 60 seconds warmup and 120 seconds measurement.

Warm moving creates no compute pipelines at run time. The engine passed 150 unit tests; Vulkan validation reports zero errors and three unused fragment-output warnings. Touch/game vibration was verified. The user physically checked gyro direction and stability in the scope. The final release APK passed save/load smoke, and production promotion verified all 19 module files and unchanged primary saves.

The final 30-minute soak was **waived by the user and not run**. Full gameplay is unverified, and the existing lower-leg ground-occlusion issue remains. BotW stays **work in progress**. No native internal 1080p, SM8750, or Mali performance claim is made. Dimensity 9400 work is isolated on a separate branch.
