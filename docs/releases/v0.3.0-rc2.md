# nxnative-android 0.3.0-rc2

First use of a new graphics pipeline could stall gameplay after the recorded startup list had finished. This candidate prepares known shaders when the game creates its programs and compiles a bounded set of upcoming pipelines on background workers. Every draw still uses its exact pipeline; incomplete preparation waits normally. The implementation adapts `seedds/nxnative` `c646d43`'s `mtl_prog_prefetch` and pending/predicted pipeline work to Vulkan.

The prior lock-poll fix, graphics/compute prewarm, ADPF hints, rumble and real gyro remain. Generic pipeline libraries are not required; the failed all-resident GPL prototype is excluded. No precision, resolution, frame target or vendor mode is changed.

## Validation and limits

- 156 source tests passed, including bounded-queue ownership, exact-key waits, queued-work stealing, private replay-state lookahead, nested records and dependency boundaries.
- 144 Android sources build. BotW 1.9.0 on TB323FU / Adreno 840 passed stationary/moving first-use Vulkan validation with recorded prewarm disabled: zero errors and three unused-output warnings. Both background paths were exercised; their worker CPU masks were 0-7.
- The user explicitly waived OFF/ON/ON/OFF. Performance gain is unquantified; the older 59.895/59.830 fps baseline measurements do not measure this change. Remaining first-use stalls and full-game compatibility are unverified.
- The previous final 30-minute soak remains waived. BotW remains work in progress; the existing lower-leg ground-occlusion issue remains. No Mali or Snapdragon 8 Elite performance claim is made.

One ordinary 120 s moving observation records 59.135 fps, 16 intervals >50 ms and a 200.011 ms maximum, at internal 1600x900 / output1080p. Remaining hitches persist; this is not evidence of a causal improvement. Release save/load and 30 s gameplay smoke pass with the packaged 1209 keys, RED=0 and unchanged primary saves/preferences. The new local runtime SHA-256 is `bcd840c1a9a3427e6dbe4f46c5caa041d6caf5f9e0fb941243e2ca42ddcc988d`; its prior runtime remains available for rollback.

Desktop bundle verification is recorded in the [follow-up](../perf-hitch-followup.md). Game files, keys, game APKs and data packs are private and excluded from the desktop release.
