## 2026-11-01：阶段 1，A/B 固定视角
- 假设：正式源码的 HOLD 默认开启会落入 30 fps 档；仅关闭 HOLD 应有可重复的整帧收益。
- 方法：底座目标配置、同一存档，每轮预热 60 s / 测 120 s，按 A/B/B/A 完成；两次失败尝试不计入对比。
- A1 / A2：29.964 / 29.679 fps，>17.5 ms 95.161% / 95.171%，P99 均 50.003 ms，最大均 58.337 ms，>50 ms 238 / 295 次。
- B1 / B2：44.160 / 44.804 fps，>17.5 ms 53.113% / 50.995%，P99 均 33.335 ms，最大 83.338 / 41.669 ms，>50 ms 2 / 0 次；全部窗口 >100 ms 均 0。
- 结论：关闭 HOLD 平均 44.482 fps，对比默认开启 29.822 fps，提升 14.660 fps；两个 B 均高于两个 A，超过有效收益门槛。
- 输出均 1920×1080；A1 内部 1600×900 → 1280×720，其余前后均 1600×900；均载入 1,063 keys，约 4,600 draws/frame，截图场景一致。
- CPU 上限 1,996,800 / 2,438,400 kHz，前后 CPU/GPU/skin 温控等级均 0，音频正常，无新 RED。
- 数据：`<BENCH>/results.csv` 及 `runs/*-A-fixed-*` / `runs/*-B-fixed-*`；下一步移动 A/B 和 C/D，尚无私有性能栈的目标配置结论。
